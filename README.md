# 파이널 판타지 익스플로러즈 (3DS) 비공식 한글패치

닌텐도 3DS 일본판 **ファイナルファンタジー エクスプローラーズ (CTR-P-BCXJ)** 비공식 한국어 패치입니다. 이 저장소에는 제작 도구와 기술 문서만 있고, 패치 파일(xdelta)은 [Releases](../../releases)에서 받을 수 있습니다. 게임 원본·일본어 원문·번역 대본은 포함하지 않습니다.

## 적용 방법
1. 아래 해시와 일치하는 **원본 `.3ds`**(복호화된 카트리지 덤프, 1GB)를 준비합니다. CIA나 암호화된 덤프에는 적용할 수 없습니다.
   - PowerShell: `Get-FileHash -Algorithm MD5 -LiteralPath '.\Final Fantasy Explorers (Japan).3ds'`
2. xdeltaUI 같은 도구로 원본에 `FFExplorers_3DS_KO_v1.0.xdelta` 를 적용합니다.
   - 명령줄: `xdelta3 -d -s "Final Fantasy Explorers (Japan).3ds" FFExplorers_3DS_KO_v1.0.xdelta "Final Fantasy Explorers (Korean).3ds"`
3. 만들어진 `.3ds`를 Azahar 등 3DS 에뮬레이터에서 실행합니다.

| 항목 | 값 |
| --- | --- |
| 원본 3DS 크기 | 1,073,741,824 바이트 |
| 원본 3DS MD5 | `8635aea2d5034d2975df5bbfc7e3c475` |
| 원본 3DS SHA-256 | `d5058ff6f17669f4f9a9a5322ac058e236eb57b20d40498cf1ddeee4a350abe3` |
| xdelta SHA-256 | `ce093939d0e2773a81ed9c182e21d716f2028d5e5c4fcba7e67fa2e59b035dec` |
| 결과 3DS 크기 | 609,488,896 바이트 |
| 결과 3DS SHA-256 | `148ac2ccd197de8010b44d819bef9e8361861627450d73bc6d75464bd5894b32` |

## 주의
- 결과 파일은 복호화 상태(NoCrypto)이고 실행 코드(`.code`)를 비압축으로 넣었습니다. **에뮬레이터 기준으로 검증**했으며, 실기(커스텀 펌웨어)에서의 동작은 확인하지 않았습니다.
- 결과 파일은 원본의 빈 공간(패딩)을 잘라내 원본보다 작습니다.

## 한글화 내용
- 게임 메시지 전체: 메시지 테이블 2개, 항목 16,290개(고유 문장 9,719개) — 대사, 퀘스트, 아이템·장비·어빌리티·몬스터 이름과 설명, 메뉴, 시스템 메시지, 도움말
- UI 레이아웃(BCLYT) 고정 라벨 150종(레이아웃 975곳)
- 실행 파일의 기본 인사말 문구
- 오프닝 동영상 내레이션 8장면: 일본어 자막은 그대로 두고 그 아래에 한글 자막 한 줄 추가(흰 글자 + 검은 테두리)
- 고유명사는 파이널 판타지 시리즈 한국어판 관례를 따랐습니다.
- 글꼴: 게임 BCFNT 폰트 2종을 새로 만들었습니다. 나눔스퀘어네오 ExtraBold로 한글 KS X 1001 2,350자 + 번역에 쓰인 글자를 넣었습니다(본문 12px 칸, 제목 15×17 칸).

## 그대로 둔 것
- 그림으로 된 글자(타이틀 로고의 가타카나 등)
- 엔딩 동영상
- 일본어 한자: 폰트 용량 때문에 한자를 뺐기 때문에, 온라인에서 다른 플레이어 이름에 한자가 있으면 `??`로 보입니다.
- 대사 속 이름 뒤 조사는 「을(를)」처럼 표기한 곳이 있습니다.

## 검증 범위
Azahar에서 타이틀, 세이브 파일 선택, 캐릭터 에디트(이름 입력 포함), 오프닝 동영상 전체까지 확인했습니다. 전체 플레이 검증은 하지 않았습니다. 화면 폭을 넘는 긴 문장은 게임이 자동으로 줄을 바꿉니다. 문제를 발견하면 Issues에 알려 주세요.
